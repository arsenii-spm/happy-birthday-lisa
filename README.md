# Открытка ко дню рождения (26.11.2010)

Статический сайт-открытка (HTML + CSS + JS), готовый к публикации на **GitHub Pages**.

## Структура проекта

- `index.html` — основная страница и модальное окно с подарком от мамы
- `styles.css` — журнальный бумажный дизайн, адаптация под телефон и ПК
- `config.js` — имена, тексты поздравлений и ключи EmailJS
- `app.js` — логика виджета с подарками, модального окна и отправки через EmailJS
- `assets/gold-apple-logo.svg` — официальный векторный знак «Золотое Яблоко»

## Как безопасно настроить отправку сертификата

Чтобы боты на GitHub не смогли скачать сертификат из публичного репозитория, **сам файл или ссылку на него не нужно хранить в коде сайта**. Вся передача идёт через закрытый шаблон EmailJS:

### 1. Загрузите сертификат в облако
Залейте реальный PDF сертификата на **Яндекс Диск** или **Google Drive** с доступом «по ссылке» (или подготовьте код сертификата). Никуда в код сайта эту ссылку не вставляйте.

### 2. Настройте EmailJS
1. Зарегистрируйтесь на [emailjs.com](https://www.emailjs.com/) (бесплатный тариф).
2. В разделе **Email Services** подключите вашу почту (Gmail / Yandex / Mail.ru) и скопируйте **Service ID**.
3. В разделе **Email Templates** создайте новый шаблон:
   - В поле **To Email** укажите: `{{to_email}}`
   - В текст письма вставьте:
     - `{{recipient_name}}` — имя получателя
     - `{{from_name}}` — подпись от мамы
     - `{{message}}` — текст поздравления
     - **Вашу ссылку на Яндекс Диск / Google Drive или код сертификата** (прямо в тексте шаблона в личном кабинете EmailJS — она не попадёт в публичный код сайта)
   - Скопируйте **Template ID**.
4. В разделе **Account → General** скопируйте **Public Key**.
5. Вставьте `publicKey`, `serviceId` и `templateId` в [config.js](file:///home/qusta/Проекты/birthday-card/config.js) в блок `emailjs`.

### 3. Опубликуйте на GitHub Pages
1. Загрузите файлы проекта в публичный репозиторий на GitHub (ветка `main`).
2. Откройте **Settings → Pages → Build and deployment → Source: `Deploy from a branch` (`main` / `/ (root)`) → Save**.
3. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
